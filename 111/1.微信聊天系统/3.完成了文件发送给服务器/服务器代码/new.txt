语言发展史
=====================================
   机器语言： 01二进制编写代码
                 12+4 --》12的二进制1100     
                          4的二进制 0100 
                          加法运算    010101
                          
   汇编语言： 在机器语言的基础上添加了助记符(汇编指令)
                 12+4 
                              
                               加法运算用人类习惯的字符串来表示 add
                               12 add 4
   B语言：
   C语言：添加大量的关键字，人类好懂的函数，循环，条件判断
          20世纪70年代，贝尔实验室的Dennis Ritchie致力于开发板UNIX操作系统，为完成这项工作，Ritchie需要一种语言，它必须简洁，能够生成简洁、快速的程序，并能有效地控制硬件，传统上，程序员使用汇编语言来满足这些需求，汇编语言依赖于计算机的内部机器语言，汇编语言针对于特定的计算机处理器，要将汇编程序移植到另一种计算机上，必须使用不同的汇编语言重新编写程序。Ritchie希望有一种语言能将低级语言的效率、硬件访问能力和高级语言的通用性、可移植性融合在一起，于是他在旧语言的基础上开发了C语言(编译器负责将高级语言翻译成特定计算机的内部语言)
   C++: 在C语音的基础上加入了面向对象的编程语法和思想(应对大型应用程序开发)

                             int  STATIC;   //正确，C语言区分大小写
                             int  Static;   //正确，C语言区分大小写

                              a=9;     //赋值
                      写法三：int a,b,c=9;  //定义多个变量，用逗号隔开

         (4)计算机存储正数和负数
                      符号位： 对于有符号的数来说，最高的二进制位是符号位 
                                   正数 0来表示
                                   负数 1来表示
                     正数的原码，反码，补码都是一样的
                     原码：一个数原本的二进制就是它的原码
                          比如：  12 --》12的二进制是   符号位0000000 00000000 00000000 00001100
                                           原码就是     符号位0000000 00000000 00000000 00001100
                     反码：把一个数的二进制位全部取反
                           比如： 12 --》   原码是   符号位0000000 00000000 00000000 00001100
                                            反码就是 符号位1111111 11111111 11111111 11110011
                     补码：反码加1得到补码
                                           补码就是 符号位1111111 11111111 11111111 11110011
                                                          0000000 00000000 00000000 00000001  相加
                                                    符号位1111111 11111111 11111111 11110100  结果

                     正数：在计算机中采用原码存储，最高位用0表示符号位
                     负数：在计算机中采用补码存储，最高位用1表示符号位
                     原码推导得到补码
                            原码取反，然后加上1即可
                     补码推导得到原码
                            补码减去1得到反码，然后反码取反得到原码
                     +0和-0的二进制都是0(-0的二进制计算的时候会改变符号位)
          (5)整数有关的类型
                   short 短整型  2字节
                   int   整型    4字节
                   long  长整型  跟机器字长有关,32位系统4个字节，64位系统8个字节
                   long long  长长整型，64位系统8个字节
                   unsigned long a=1500UL  //UL表示无符号长整型
             有符号和无符号的区别
                   有符号的数：最高位用0或者1表示符号
                   无符号的数：没有正负之分，就是纯数字，最高位也是数据位
             无符号和有符号数据相加减
                   结果默认当成无符号数处理，除非你把结果赋值给有符号的变量                        
          (6)浮点数
                  float 单精度浮点  4字节
                  double 双精度浮点 8字节
                  浮点数在计算机中也是用二进制存储
                  某些浮点数在计算机中是无法精准表示
                  float： 符号位1位    指数位(阶码)8位(+127)     小数部分23位
                  double：符号位1位    指数位(阶码)11位(+1023)   小数部分52位
                     比如：float类型 12.36
                            第一步：先计算整数部分的二进制以及小数部分的二进制(小数部分不断地乘以2,取整)
                            第二步：整数部分二进制.小数部分二进制 --》把小数点往左边移动,只保留一位整数
                            第三步：依据float的存储格式存储二进制,注意指数位要+127然后存储  
          (7)布尔类型 占1个字节(有些同学会以为跟整数一样占4个字节)
                  sizeof(true)  //4个字节
                  sizeof(bool)  //1个字节
                  bool b=true； //正常人都会觉得跟true大小一样,但是实际上b是bool类型，跟bool类型一样是1个字节
                  sizeof(b)  //1个字节
                  #include <stdbool.h>
                    #define true  1
                    #define false 0
                  true  //真   打印出来，值就是1
                  false //假   打印出来，值就是0
                  C语言规定 0就是假，非0(-1,10,78)就是真 
          (8)强制类型转换
                  为什么要转换：C语言规定数据类型在赋值的时候完美的情况是类型保持一致
                  自动转换: 不需要人为干预,某些情况下有精度的损失
                            char和int
                            int和float,double
                            高精度赋值给低精度--》有损失
                            低精度赋值给高精度--》没有损失
                  强制转换: 一般不同类型指针需要用到强转


格式控制符号
=====================================  
   1.常见的格式控制符号
      %c  %d  %hd 短整型   %ld 长整型   %hu 无符号短整型  %f  %lf   %s(打印字符串)   %p(打印变量的首地址)   %x 16进制   %o 八进制   %#x 16进制会加上前缀0x   %#o 八进制会加上前缀0  
      %lu 无符号长整型  %hhu无符号字符类型   %u无符号的整型
      %i 可以打印10进制，也可以获取键盘输入的8进制(输入的时候加上0)和16进制(输入的时候加上0x)
      %X 16进制，遇到字母用大写表示
      %10d   %10.5f   %10c
   2.位宽和小数位数设置
      %10d  -->10表示位宽,正的10表示数据靠右边
      %-10d -->10表示位宽,负的10表示数据靠左边
      %10.5f -->10表示位宽,小数点后面的5表示保留5位小数
      %.5f -->小数点后面的5表示保留5位小数
      注意：位宽设置规律
                 位宽大于数据原本的位数--》填充空格来凑齐位宽
                 位宽小于数据原本的位数--》数据原样输出，不会截取
   3.转义字符
      \\n --》回车转义了
      \\  --》打印\，\必须转义，单独的\编译语法错误
      \\\\ --》打印两个斜杠
      双引号嵌套，里面的双引号必须转义
      '\14'或者'\17'   //是个字符，只能是八进制的数，前面不要写上0  
      '\x89'或者'\xa1'  //是个字符，只能是十六进制的数
      可见字符和不可见字符
             可见字符：你使用%c可以打印出来肉眼看得到的字符
             不可见字符：你使用%c可以打印出来肉眼看不到的字符
   4.续行符\
      作用：当你写的一句代码，逻辑上是个整体，但是你有需要切换到多行去写，此时就要使用续行符
